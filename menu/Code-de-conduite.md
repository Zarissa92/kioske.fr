## Code de conduite

KiosKe est un projet où chacun·e peut proposer des sources, signaler un problème ou discuter. Le code de conduite dit comment on se parle et ce qui n'est pas accepté, sur le site comme sur le Discord.

**[Lire le code de conduite](/code-de-conduite.html)**

Il s'applique à tous les espaces du projet.
